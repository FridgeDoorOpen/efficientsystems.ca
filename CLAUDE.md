# efficientsystems.ca

The public ESC site. See README.md for layout, building and serving.
See ../CLAUDE.md for how this repo relates to house, esc-model and historian.

## Rules
- `build.py` may only write the paths in `OWNED`. Never write into public/teaching/
  (Shreya's classroom tools) or public/robots.txt.
- Every figure follows the visual grammar in content/legend.md and uses the
  `f-` CSS classes in static/style.css. No inline colours.
- Every SVG needs role="img" and a <title> that states its argument in words,
  so agents can read it.
- Figures are drawn by figures/ (in progress). Principle figures in content/ are
  hand-authored arguments; model views are generated from data.
- Data from house arrives only as a copy of ../house/exports/public.yaml in content/models/.
  Never read ../house/model, and never widen what's exported from this repo: that's the
  house policy's job.
- Generated files carry a "generated by …, do not edit" comment and are committed,
  so figure changes show up in git diffs.
